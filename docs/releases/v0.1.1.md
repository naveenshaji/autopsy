# Autopsy Memory v0.1.1

Private release date: 2026-05-16

## Summary

This release adds the CLI-first first-run setup flow.

## Install

```bash
./scripts/install-global.sh
autopsy version --json
autopsy init --check
autopsy init
```

## Included

- `autopsy init` installs managed Autopsy memory instruction blocks for Codex and Claude Code.
- Global targets: `~/.codex/AGENTS.md` and `~/.claude/CLAUDE.md`.
- Repo targets: `AGENTS.md` and `CLAUDE.md`.
- Safe modes: `--check`, `--dry-run`, and managed block markers.
- Utility modes: `--print`, `--mcp`, `--agent`, `--global`, `--repo`, and `--smoke-test`.
- CI and release checks now exercise `autopsy init --check`.

## Integration Policy

Persistent instructions plus the `autopsy` CLI are the default integration path. MCP remains optional and is only printed when requested with `autopsy init --mcp`.
