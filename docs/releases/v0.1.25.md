# Autopsy Memory v0.1.25

Patch release for the live context graph rollout.

## Changes

- Updates generated Codex instructions so context graph URLs are opened in the Codex in-app Browser through the `iab` browser-control path, not through `web.run`, macOS `open`, or the default browser.
- Keeps `autopsy context-graph-url` guidance explicit: print the URL without `--open`, then navigate the selected or newly created in-app Browser tab with `tab.goto(URL)`.
- Adds a Homebrew formula updater fallback from GitHub's archive wrapper URL to the equivalent `codeload.github.com` tarball when the wrapper returns a transient 504.
- Updates the local Homebrew current-formula check so it can patch either archive URL shape during local source validation.

## Validation

```bash
PYTHONPATH=src python -m unittest tests.test_init tests.test_homebrew_formula
./scripts/release-check.sh
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.25 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
./scripts/homebrew-current-check.sh
```
