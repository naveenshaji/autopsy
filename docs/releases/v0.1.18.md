# Autopsy Memory v0.1.18

Homebrew runtime path-space fix.

## Highlights

- Moves embedded Redis logs to a stable temp log directory instead of the default macOS app support path, avoiding Redis config failures on `Application Support`.
- Keeps `autopsy doctor` and structured startup diagnostics pointing at the new log path.
- Excludes the native FalkorDB `.so` resource from Homebrew's Python virtualenv installer while still staging it for Autopsy wrappers.
- Keeps the v0.1.17 self-contained Apple Silicon Homebrew runtime fix intact.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.18 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
brew test --force naveenshaji/autopsy/autopsy-memory
```
