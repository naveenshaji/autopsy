# Autopsy Memory v0.1.2

Private release focused on product hardening.

## Highlights

- Adds `autopsy restore` and `autopsy import` for backup restore workflows.
- Restore defaults to merge mode, supports `--dry-run`, skips operational nodes unless requested, and requires `--replace --yes` for matching-key replacement.
- Adds `autopsy health` for runtime, graph, index, vector, backup, and init-instruction status.
- Tightens consult workflow metadata so weak side-channel candidates are reported as `weak_signals_only` instead of reliable partial answers.
- Adds write-quality warnings for short, low-signal, duplicate, or title-equals-content writes.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy health
autopsy benchmark --sample-size 5 --include-sync
```
