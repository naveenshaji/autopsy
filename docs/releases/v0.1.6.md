# Autopsy Memory v0.1.6

Private menu bar UI update for native macOS styling.

## Highlights

- Replaces custom activity count capsules with a native sectioned SwiftUI `List`.
- Replaces custom material attention cards with plain list rows.
- Uses default macOS `Button`, `Toggle`, `Label`, `Section`, and `List` styling wherever the menu bar surface needs ordinary utility controls.
- Keeps the popover focused on status, recent writes, recent consults, attention, login startup, notification preference, health, backup, settings, and quit.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
