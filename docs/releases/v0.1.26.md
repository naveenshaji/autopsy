# Autopsy Memory v0.1.26

Patch release for Codex hook-mode context graph session resolution.

## Changes

- Resolves Codex context graph URLs with `autopsy context-graph-url --codex-current`, using only fresh trusted Codex hook session state.
- Rejects manual `--thread-id` graph URL requests while hook mode is active, and ignores environment thread-id fallbacks so agents cannot invent graph ids.
- Adds a `PreToolUse` hook state refresh that records the current Codex session id without creating graph events.
- Keeps generated Codex instructions explicit about using the Codex in-app Browser and never retrying stale hook state with a fabricated id.
- Retries `context`, `health`, and `benchmark` once after stale embedded FalkorDB socket/runtime state.
- Cleans local Homebrew stale-keg handling during validation so strict audit sees only the active installed version.

## Validation

```bash
PYTHONPATH=src python -m unittest discover -s tests
autopsy health
autopsy benchmark --sample-size 5 --include-sync
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
```
