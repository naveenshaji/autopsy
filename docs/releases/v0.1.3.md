# Autopsy Memory v0.1.3

Private release replacing Observatory with a quiet native macOS menu bar companion.

## Highlights

- Removes the Tauri/Svelte Observatory graph browser product surface.
- Adds a SwiftPM `AutopsyMenuBar` MenuBarExtra app for recent writes, recent consults, status, health, backup, and settings.
- Adds `autopsy activity` as the lightweight JSON feed for UI clients.
- Adds `autopsy menubar` to launch, build, or locate the installed menu bar app source.
- Updates install packaging and release checks so the Homebrew-style install includes the menu bar app source.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy activity --limit 3
autopsy menubar --print-path
autopsy menubar
```
