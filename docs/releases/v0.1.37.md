# Autopsy 0.1.37

`autopsy repair-ids` now also repairs edges: it gives every edge that shares an edge id with another edge a new one, and it removes extra copies of structural edges stored twice between the same two nodes. Session imports now write each structural edge in one query, so a second writer can't add a copy.

Before 0.1.36, edge ids were allocated the same racy way as entity ids. Separate writes running at the same time could give different edges the same `edge_id`. The 0.1.36 repair only re-ids edges inside one fanned-out write, so these stayed. Of each group, the earliest edge keeps its id and the others get fresh ones from the counter.

A structural edge (such as `PART_OF`, `CAPTURES`, `ABOUT` or `FOLLOWS`) is meant to exist once between two nodes. When it was stored more than once, the earliest copy is kept and the rest are deleted. Parallel `FACT_EDGE` relations are left alone: each is a fact someone wrote separately, and restore deliberately keeps them.

`autopsy repair-ids` prints both plans, the entity-id plan and the new `edge_plan`. `--apply` takes the same verified backup and guard lock as before. It repairs entity ids first, then plans the edge repair again against the result and applies it. Every write re-checks the edge it targets, so a stale plan does nothing.

Structural edges are now created with `MERGE`, matching endpoints by stable key, instead of an existence check followed by a separate `CREATE` that matched by entity id. This takes two queries on the create path instead of four.

Validation: 431 automated tests, including embedded-FalkorDB round trips of the edge repair, of parallel facts being kept, and of a structural edge written by two importers that both found it missing. On a copy of the live 13,470-node graph, the repair gave 34 edges new ids and removed 2 doubled session edges in 6.7 s, including the backup. Node count was unchanged, no edge ids were shared afterwards, and a second plan found nothing. Session imports through both importers on that copy then added no shared edge ids or doubled edges.
