# Autopsy Memory v0.1.24

Live context graph release.

## Changes

- Adds the local web context graph viewer with draggable node cards, rounded edges, neutral light/dark themes, dotted canvas, animated node arrivals, multi-turn turn separation, and scrollable node/edge inspectors.
- Serves signed per-thread context graph URLs from the Autopsy worker and packages the built viewer assets into the Python wheel.
- Adds silent allowlisted command capture through `autopsy context-event` for CLI-mode agents.
- Adds Codex hook ingestion through `autopsy codex-hook`, recording only allowlisted `PostToolUse` Bash command text after the user trusts the hook.
- Keeps graph capture tightly scoped to exact command text for read/context commands, skipping generic lifecycle/tool-result events, command output, secrets, writes, builds, tests, package commands, shell redirection, command substitution, and background operators.
- Adds context graph settings for enabling/disabling capture, choosing hooks versus CLI mode, and toggling multi-turn graph behavior.
- Adds a standard macOS Settings window to the menu bar app with About, Context Graph, and Memory tabs.
- Updates managed agent instructions so Codex opens graph URLs in the in-app browser and stops calling `context-event` when hook mode is active.
- Builds the context graph frontend during release checks and global installs, using Autopsy-owned npm caches.
