# Autopsy Memory v0.1.10

Private menu bar startup-state update.

## Highlights

- Shows the last successful activity payload immediately after the menu bar app starts.
- Keeps recent writes, recent consults, attention, and status visible while the first refresh runs.
- Reuses the last known LaunchAgent status until the startup check completes.
- Keeps the last successful update time intact when refresh fails.
- Fixes write notifications after an initial empty activity feed.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
