# Autopsy Memory v0.1.4

Private hotfix for native menu bar launch stability.

## Highlights

- Changes `autopsy menubar` to build the SwiftPM product, stage a minimal `AutopsyMenuBar.app` bundle, and open that bundle with LaunchServices.
- Gives the menu bar app a stable bundle identifier so macOS services such as notifications have an app identity.
- Prevents direct unbundled `swift run` launches from touching UserNotifications APIs.
- Extends `autopsy menubar --print-path` with the staged app bundle path.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --build
autopsy menubar --print-path
autopsy menubar
```
