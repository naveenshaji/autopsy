# Autopsy Memory v0.1.16

Neutral memory-root default.

## Highlights

- Replaces the personal development default `~/github/codex` with `~/Library/Application Support/Autopsy/MemoryRoot`.
- Aligns the CLI, worker, and MCP bridge around the same neutral default.
- Keeps `AUTOPSY_UNIFIED_MEMORY_ROOT` as the explicit override for custom installs.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.16 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
