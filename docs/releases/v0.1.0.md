# Autopsy Memory v0.1.0

Private release date: 2026-05-16

## Summary

Autopsy Memory is now split from the legacy macOS client and ships as a standalone local-first memory CLI and service layer.

## Install

```bash
./scripts/install-global.sh
autopsy version --json
autopsy doctor
autopsy benchmark --sample-size 5 --include-sync
```

## Included

- Falkor-backed graph memory with strict Falkor-only persistence.
- Top-level `autopsy` CLI with compatibility support for `autopsy memory ...`.
- MCP bridge and worker entrypoints.
- Typed memory writes and explicit semantic relations.
- Export and backup commands for portable JSON recovery.
- Benchmark gate for recall, abstention, latency, writes, relations, scale readiness, and Falkor health.
- Homebrew-style global install flow.
- Doctor check that rejects the stale legacy app wrapper.

## Known Limits

- The benchmark is an internal product gate, not a public leaderboard.
- Large-scale public corpus evaluation is not included yet.
- CLI internals have started modularization, but deeper graph/retrieval/write package boundaries still need follow-up refactors.
