# Autopsy Memory v0.1.32

Reliability, retrieval accuracy, and recovery improvements. Existing memory graphs
and agent instructions remain in place; this release requires no destructive
migration.

## Recovery

- Every successful memory mutation creates a full recovery snapshot. A snapshot
  from before the write no longer counts as coverage for it.
- Opt-in iCloud Drive copies have SHA-256 verification, persistent status, and
  retries. Local backups survive unavailable cloud storage. Upload to Apple's
  servers is reported as unknown rather than inferred from a local copy.
- Snapshots use compact JSON, unique names, durable atomic publication, and
  required integrity sidecars. Previous backups are never overwritten or pruned.
- Full backups preserve history properties, source episodes, timestamps, exact
  text, feedback, metadata, and parallel relations. Restore rejects malformed or
  corrupted inputs before mutation and can resolve existing external endpoints.
- Backup status detects failed copies and destination changes. Partial exports
  use `export --limit`; recovery backups always cover the full graph.

## Runtime and retrieval

- Worker and MCP transport recovery no longer replay potentially committed writes.
  Ambiguous outcomes direct callers to inspect memory/history before retrying.
- Active requests prevent idle shutdown; malformed or truncated requests fail
  safely. Concurrent cold requests initialize each model once.
- Combined namespace, entity scope, tag, and metadata filters retain matching
  memories and hydrate metadata in one compact query.
- Transient vector failures no longer suppress semantic retrieval indefinitely.
  Direct retrieval remains available when embedding generation fails.

## Validation

- Python unit and regression tests, including fault injection for write replay,
  interrupted backups, cloud failures, and metadata filtering.
- Isolated FalkorDB round trips for exact text, history, timestamps, metadata,
  parallel edge preservation, and repeated restore idempotence.
- Full recovery rehearsal restored 9,265 nodes, 7,126 semantic relations, and
  15,710 structural links with zero missing, extra, or changed portable data.
- Fresh-environment packaging, installation, CLI checks, and macOS menu bar build.
- Existing agent instructions remain unchanged.

See [backup and recovery](../backups.md) to enable iCloud copies and restore safely.
