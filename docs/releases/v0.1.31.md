# Autopsy Memory v0.1.31

Embedded runtime recovery release.

## Changes

- Serializes embedded FalkorDB startup across threads and processes with a
  per-database runtime lock.
- Enforces exactly one embedded Redis/FalkorDB runtime and makes duplicate
  owners a required CLI and resident-worker health failure.
- Prevents concurrent post-restart startup from producing multiple writers for
  the same persisted database.

## Validation

- Full Python unit suite.
- Release packaging and installation checks.
- Concurrent cold-start and persisted-restart probes.
- Homebrew formula generation, style, audit, fetch, and packaged runtime health.
