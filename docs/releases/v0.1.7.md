# Autopsy Memory v0.1.7

Private menu bar update for native macOS command behavior.

## Highlights

- Adds a native Commands menu for refresh, health, backup, settings, and quit.
- Adds standard keyboard shortcuts from the menu bar popover:
  - `Command-R` refreshes activity.
  - `Command-,` opens Settings.
  - `Command-Q` quits Autopsy.
- Keeps health and backup visible as ordinary controls without assigning nonstandard shortcuts.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
