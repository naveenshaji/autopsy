# Autopsy Memory v0.1.13

Public Homebrew-ready menu bar release.

## Highlights

- Adds a Homebrew tap formula for `autopsy-memory` with pinned Python resources.
- Adds `scripts/update-homebrew-formula.py` so the formula can be regenerated from a public release tag.
- Documents the owned tap install path and the future `homebrew/core` requirements.
- Refines the native menu bar utility into a tabbed Writes/Consults activity surface.
- Makes hover details full-height and adds Show More/Show Less for long memory text.
- Removes the broken write-notification toggle and visible refresh indicator.
- Adds broader agent instruction status/install support and an explicit Quit action.
- Keeps Homebrew-style menu bar startup pinned to the stable `opt/autopsy-memory` path.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.13 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
