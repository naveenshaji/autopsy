# Autopsy Memory v0.1.19

Menu bar activity and small-screen detail fix.

## Highlights

- Packages the menu bar app with the stable Homebrew wrapper path instead of the raw virtualenv entrypoint.
- Self-heals stale cached Cellar `libexec/bin/autopsy` paths inside the Swift menu bar app.
- Adds a defensive process environment fallback so direct Cellar paths still get unified memory mode and the native FalkorDB module path.
- Keeps the hover detail area from resizing the popover on normal screens, preventing side-to-side placement flicker.
- Switches narrow screens to an in-place detail panel instead of a side flyout.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.19 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew reinstall --build-from-source naveenshaji/autopsy/autopsy-memory
brew test --force naveenshaji/autopsy/autopsy-memory
```
