# Autopsy Memory v0.1.28

Patch release for live context graph memory visibility and worker liveness.

## Changes

- Shows memory writes directly in the context graph using Autopsy's current Codex hook thread state, instead of relying on command-capture hooks for write commands.
- Hardens generated Codex instructions so agents can consult Autopsy multiple times and write multiple distinct memories in one turn when the work calls for it.
- Keeps the context graph visible across resumed or long Codex chats by telling agents to reopen missing or stale in-app Browser graph tabs.
- Adds a hidden menu bar worker keepalive command and has the native menu bar app run it silently while the LaunchAgent is active, so local graph routes stay warm without agents rerunning `context-graph-url` just to revive the server.
