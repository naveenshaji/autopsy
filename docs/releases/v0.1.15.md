# Autopsy Memory v0.1.15

First-run setup simplification.

## Highlights

- Adds `autopsy install` as the normal setup command after Homebrew install.
- Installs or updates global agent instructions for supported agent harnesses.
- On macOS, stages the menu bar app bundle and installs/starts the LaunchAgent.
- Keeps repo-local instructions opt-in with `autopsy install --repo`.
- Leaves `autopsy menubar --install-launch-agent` available as the lower-level diagnostic path.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.15 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
