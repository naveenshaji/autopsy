# Autopsy Memory v0.1.22

ML runtime packaging release.

## Changes

- Makes `sentence-transformers` part of the base Autopsy runtime so semantic vector retrieval and reranking are no longer an optional install tier.
- Updates `doctor`, `health`, and worker health checks to treat `sentence_transformers` as required.
- Updates Homebrew formula generation to package resolver-selected wheel artifacts, including macOS arm64 wheels for the compiled ML stack.
- Keeps the legacy `ml` Python extra as a no-op compatibility alias so older install commands continue to work.
- Updates end-user docs to describe model downloads as first-use model-weight downloads rather than an optional feature.

## Verification

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.22 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
