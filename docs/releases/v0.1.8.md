# Autopsy Memory v0.1.8

Private menu bar feedback update.

## Highlights

- Restores visible success feedback for utility actions after the native-list popover refactor.
- Shows health, backup, and login-startup results in the native status row footnote.
- Clears stale action text when a new utility action starts.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
