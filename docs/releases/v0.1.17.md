# Autopsy Memory v0.1.17

Self-contained Apple Silicon Homebrew runtime fix.

## Highlights

- Vendors the native Darwin arm64 FalkorDB module in the Homebrew formula.
- Sets `AUTOPSY_FALKORDB_MODULE_PATH` in the installed CLI, MCP, and worker wrappers.
- Adds a real embedded FalkorDB runtime probe to `autopsy doctor`.
- Replaces raw backend startup tracebacks with structured JSON diagnostics and Redis log tails.
- Keeps Homebrew as the preferred macOS distribution path while PyPI `falkordblite` lacks a native Darwin module.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.17 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
