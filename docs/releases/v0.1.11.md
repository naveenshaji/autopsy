# Autopsy Memory v0.1.11

Private menu bar structure update.

## Highlights

- Replaces the sectioned `List` popover with a compact menu-stack layout.
- Borrows `codex-account-switcher` structure: compact header, divider-separated rows, plain hover action rows, and short visible labels.
- Reduces visual weight by showing the top recent writes and consults instead of a taller app-like list.
- Keeps full long titles and summaries available through tooltips.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
