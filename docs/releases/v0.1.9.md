# Autopsy Memory v0.1.9

Private menu bar login-item stability update.

## Highlights

- Keeps the user LaunchAgent pointed at the stable Homebrew-style `opt` path when available.
- Prevents login startup from depending on one versioned Cellar directory after updates.
- Uses release app bundles by default for Homebrew-style menu bar launches.
- Prestages the release menu bar app bundle during the global installer on macOS.
- Preserves explicit custom `--dir` behavior for source and development runs.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --install-launch-agent
autopsy menubar --launch-agent-status
autopsy menubar --uninstall-launch-agent
```
