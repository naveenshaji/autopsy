# Autopsy Memory v0.1.14

Homebrew install hotfix.

## Highlights

- Fixes `brew install autopsy-memory` failing while building the Swift menu bar app.
- Disables SwiftPM's nested sandbox for `autopsy menubar --build`.
- Uses package-local SwiftPM cache, configuration, and security directories under `menubar/.build`.
- Ensures Homebrew can finish the install and link the `autopsy` CLI.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.14 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew style naveenshaji/autopsy/autopsy-memory
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
