# Autopsy Memory v0.1.5

Private menu bar UX update for normal daily use.

## Highlights

- Changes `autopsy menubar` to reuse a current staged app bundle instead of rebuilding on every launch.
- Opens the staged app bundle without forcing duplicate menu bar instances.
- Adds `autopsy menubar --rebuild` for explicit rebuilds.
- Adds LaunchAgent install/status/uninstall commands so the utility can open at login.
- Exposes the same login-startup state in the app Settings window as **Open Autopsy at Login**.
- Adds menu bar CLI timeouts so slow activity, health, backup, or startup checks fail visibly instead of spinning indefinitely.
- Shows compact recent write, consult, attention, and login-startup status in the popover.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar --launch-agent-status
autopsy menubar
```
