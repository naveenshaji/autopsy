# Autopsy Memory v0.1.12

Private menu-bar-only surface update.

## Highlights

- Removes the separate SwiftUI Settings scene and app command menu from the native menu bar utility.
- Moves login startup into the popover as an **Open at Login** menu toggle row.
- Keeps command recovery in the popover with **Use Detected Command** when a custom stored CLI path differs from the bundled default.
- Keeps the utility aligned with `codex-account-switcher`: one menu bar extra window, compact rows, no app-style settings window.

## Validation

Run before relying on the release:

```bash
./scripts/release-check.sh
./scripts/install-global.sh
autopsy version --json
autopsy menubar --print-path
autopsy menubar
```
