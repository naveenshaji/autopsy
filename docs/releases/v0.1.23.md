# Autopsy Memory v0.1.23

Menu bar quieting and model warmup release.

## Changes

- Hides the visible "Setup Needs Attention" diagnostics row from the menu bar app so the surface stays quiet for end users.
- Changes plain `autopsy menubar` to install and kickstart the supervised LaunchAgent by default in GUI sessions instead of opening a fragile one-off app.
- Resolves menu bar app directories to absolute paths before writing LaunchAgent plists, including local `--dir apps/menubar` launches.
- Adds `autopsy model-warmup` to download and warm the local embedding and reranker models.
- Starts model warmup in the background after `autopsy install`, with logs and status under `~/Library/Application Support/Autopsy`.
- Updates end-user README positioning to compare Autopsy with markdown memory, copied summaries, plain vector memory, and hosted memory services.

## Verification

Run before relying on the release:

```bash
./scripts/release-check.sh
python -m unittest discover -s tests
swift build -c release --package-path apps/menubar --cache-path apps/menubar/.build/swiftpm/cache --config-path apps/menubar/.build/swiftpm/configuration --security-path apps/menubar/.build/swiftpm/security --manifest-cache shared
autopsy health
autopsy benchmark --sample-size 5 --include-sync
```

After the tag exists, regenerate and validate the Homebrew formula:

```bash
/opt/homebrew/opt/python@3.12/libexec/bin/python scripts/update-homebrew-formula.py --version 0.1.23 --python /opt/homebrew/opt/python@3.12/libexec/bin/python
brew audit --formula --strict naveenshaji/autopsy/autopsy-memory
brew fetch --formula --deps naveenshaji/autopsy/autopsy-memory
```
